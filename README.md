 Interactive Excel  dashboard to analyze and visualize global conflicts, casualties, and trends using real-world data.
 


Global Conflict Analysis Dashboard (1948 – 2026)

*Advanced Excel Dashboard for Humanitarian Data Analysis*

An interactive Excel dashboard built to analyze 27 major global conflicts from 1948 to 2026. The dashboard transforms raw conflict data into meaningful insights on casualties, displacement, and humanitarian impact.

*Project Objective*
The goal of this project was to clean, process, and visualize historical conflict data to understand patterns of war, displacement, and civilian impact. The dashboard helps decision-makers and researchers quickly identify trends, compare conflicts, and extract humanitarian insights.

*Dataset Overview*
- *Source*: Historical conflict dataset - 27 major conflicts
- *Time Period*: 1948 – 2026
- *Key Fields*: Estimated Deaths, Civilian Casualties, Displaced Persons, Refugees, Affected Population, Reliability Score

*Data Cleaning & Transformation*
Performed extensive data preparation in Excel:
1. *Symbol Removal*: Removed unnecessary symbols like `~` and `+`
2. *Value Standardization*: Converted values like `4M` and `500K` to numeric format
3. *Missing Value Handling*: Treated and imputed missing data points
4. *New Metrics Created*:
    - `Estimated Deaths` = Average of Lower and Upper Estimated Deaths
    - `Civilian Men` and `Civilian Women` calculated from percentages and total civilian deaths for consistency
5. *Column Exclusion*: Excluded ambiguous columns like `Military Killed Side A/B` due to lack of group/country mapping

*Dashboard Features*
Built entirely using Advanced Excel with PivotTables, Slicers, and Charts.

*6 Key KPIs:*
- Total Conflicts
- Estimated Deaths
- Total Affected Population
- Total Displaced Persons
- Total Refugees Abroad
- Average Reliability Score

*5 Interactive Visualizations:*
1. *Top 10 Deadliest Conflicts* - Bar Chart
2. *Top Conflicts by Affected Population* - Column Chart
3. *Civilian Casualty Distribution* - Pie/Donut Chart
4. *Direct vs. Indirect Deaths* - Comparative Chart
5. *Displaced Persons vs. Refugees* - Comparison Chart

*Interactivity:*
Conflict Name Slicer allows users to filter the entire dashboard for a specific conflict. Clearing the filter resets to overall analysis. Dashboard includes usage instructions for easy navigation.

*Key Insights*
Analysis revealed that large-scale conflicts such as the *Syrian Civil War* and the *Iran-Iraq War* had the highest humanitarian impact in terms of deaths, displacement, and affected population.

*Tools & Skills Used*
`Microsoft Excel` `PivotTables` `Slicers` `Charts` `Data Cleaning` `Data Transformation` `Power Query` `Analytical Thinking` `Data Visualization`

*How to Use*
1. Download the repository
2. Open `Global_Conflict_Dashboard.xlsx`
3. Use the `Conflict Name Slicer` on the right to filter by specific conflict
4. Clear the slicer to view overall data
